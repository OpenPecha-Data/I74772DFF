## Title
	- དཔལ་འཁོར་ལོ་བདེ་མཆོག་ལྷ་ལྔའི་དཀྱིལ་ཆོག་གི་མཆོད་གཞི་བཅའ་བསྒྲིགས་འདོན་ཟིན་ཕྱག་ལེན་རྣམས་ཞིབ་བཀོད། གདངས་དབྱངས་འཐེན་གྲངས་བཅས་ཁ་གསལ་གོ་བདེ་ཕྱོགས་གཅིག་ཏུ་བཀོད་པ།
	- དཔལ་ལྡན་ལྷན་ཅིག་སྐྱེས་མ་རྡོ་རྗེ་རྣལ་འབྱོར་མའི་མཆོད་གཞི་བཅའ་བསྒྲིགས་འདོན་ཟིན་ཕྱག་ལེན་རྣམས་ཞིབ་བཀོད། གདངས་དབྱངས་འཐེན་གྲངས་སྦྱིན་སྲེག་འདོན་ཟིན་ཕྱག་ལེན་རྣམས་ཁ་གསལ་ཕྱོགས་གཅིག་ཏུ་བཀོད་པ།
	- དཔལ་འཇིག་རྟེན་དབང་ཕྱུག་རྒྱལ་བ་རྒྱ་མཚོའི་དཀྱིལ་ཆོག་གི་མཆོད་གཞིའི་བཅའ་བསྒྲིགས་འདོན་ཟིན་ཕྱག་ལེན་རྣམས་ཞིབ་བཀོད་དང་། སྦྱིན་སྲེག་གི་འདོན་ཟིན་ཕྱག་ལེན་ཁ་གསལ། གདངས་དབྱངས་འཐེན་གྲངས་རྡུལ་ཚོན་ཆུ་གཤེགས་སེར་ཕྲེང་།
	- དཔལ་དུས་ཀྱི་འཁོར་ལོའི་སྒྲུབ་པ་ཉམས་ལེན་དང་མཆོད་གཞི་བཅའ་བསྒྲིགས་འདོན་ཟིན་ཕྱག་ལེན་རྣམས་ཕྱོགས་གཅིག་ཏུ་བཀོད་པ།
